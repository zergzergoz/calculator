# Odium World Calculator Web — prototype 0.3

Веб-прототип создан на базе desktop v1.6.9. Он не требует Electron и готов к размещению как статический сайт.

## Что уже работает

- главное меню, включая неактивную кнопку «Полезные функции»;
- интерактивная карта ресурсов;
- караванные ресурсы;
- сквады и их встроенные Wiki-данные;
- рейдовые боссы и их встроенные Wiki-данные;
- чемпионы: 320 точек появления с фильтрами 50+, 60+, 75+, 76+;
- алтари: 111 точек, разделение на соло/групповые и фильтры 50+, 60+, 65+;
- калькулятор крафта;
- калькулятор талантов;
- калькулятор алхимии;
- экспорт/импорт билдов талантов через JSON;
- экспорт/импорт пользовательских маршрутов через JSON;
- PWA-манифест и сервис-воркер с кэшированием посещённых ресурсов.

## Ограничение prototype 0.1

Кнопки обновления данных из Odium World Wiki в веб-версии отключены. Браузер не должен напрямую повторять desktop-механику Electron/API: для безопасной и стабильной актуализации нужен небольшой backend/serverless proxy. Встроенные базы уже содержат данные desktop v1.6.9 и обновляются при публикации новой версии сайта.

## Локальный запуск

Рекомендуется запуск через HTTP, а не `file://`:

```bash
python -m http.server 8080
```

После этого открыть `http://localhost:8080/`.

## GitHub Pages

Содержимое этой папки можно разместить в отдельном репозитории, например `odium-world-calculator-web`.

1. Загрузить содержимое папки в корень репозитория.
2. Открыть `Settings → Pages`.
3. В `Build and deployment` выбрать `Deploy from a branch`.
4. Выбрать ветку `main` и папку `/ (root)`.
5. Сохранить настройки.

После публикации сайт будет доступен по адресу вида:

`https://zergzergoz.github.io/odium-world-calculator-web/`

Относительные пути уже рассчитаны на размещение в подпапке GitHub Pages.


## Анонимная статистика (опционально)

В v0.2 добавлена заготовка скрытой статистики через Cloudflare Worker + D1. По умолчанию она выключена, пока не указан URL собственного Worker. Инструкция находится в `cloudflare-stats/README.md`.

Сайт не отправляет IP, User-Agent, геолокацию, путь страницы или другие пользовательские данные в нашу D1. На сервер уходит только дневной анонимный ID, который меняется каждый UTC-день. Публичной админ-панели и публичного endpoint чтения статистики нет.

## Изменения Web 0.3

На интерактивной карте добавлены режимы «Чемпионы» и «Алтари». Для каждой точки доступны координаты X/Y/Z, фильтрация по уровню, переход к точке из списка и отдельные маркеры на карте. Для алтарей дополнительно есть фильтр «Соло / Групповые».
