# Odium World Calculator — скрытая анонимная статистика

Этот Worker хранит только данные, необходимые для двух показателей:

- уникальные браузеры за UTC-день;
- максимальное число одновременно активных браузеров за UTC-день.

## Что НЕ собирается

Код приложения не записывает IP-адрес, User-Agent, геолокацию, страницу, реферер, аккаунт, имя или другие пользовательские сведения. Браузер отправляет только поле `id` — 128-битный дневной псевдоним. Он вычисляется из случайного локального seed и меняется каждый UTC-день; сам seed на сервер не отправляется.

Cloudflare как инфраструктурный провайдер технически обрабатывает сетевые запросы, но этот Worker не читает и не сохраняет сетевые идентификаторы в D1. Observability в `wrangler.jsonc` отключена.

## Данные в D1

`daily_visitors` содержит дневной псевдоним и timestamps первого/последнего heartbeat. Записи старше двух дней удаляются ежедневным Cron Trigger.

`daily_stats` содержит только агрегаты по дням и хранится без идентификаторов пользователей.

## Развёртывание

1. Установить Node.js LTS.
2. В этой папке выполнить `npm install`.
3. Выполнить `npx wrangler login` и подтвердить вход в Cloudflare.
4. Создать D1: `npm run db:create`.
5. Команда покажет `database_id`. Вставить его вместо `REPLACE_WITH_DATABASE_ID` в `wrangler.jsonc`.
6. Создать таблицы: `npm run db:init`.
7. Развернуть Worker: `npm run deploy`.
8. Wrangler покажет адрес вида `https://odium-world-calculator-stats.<subdomain>.workers.dev`.
9. В корневом `../stats-config.js` вставить `<адрес>/heartbeat` и поставить `enabled: true`.
10. Загрузить изменённую веб-версию в GitHub Pages.

Для GitHub Pages разрешён origin `https://zergzergoz.github.io`. Для локальной проверки также разрешены `http://localhost:8080` и `http://127.0.0.1:8080`.

## Просмотр статистики без админ-панели

Сегодня:

```bash
npm run stats:today
```

Последние 60 дней:

```bash
npm run stats:history
```

Эти команды читают закрытую D1 через твой авторизованный Wrangler; публичного API для статистики нет.

## Определение online

Браузер отправляет heartbeat примерно раз в 60 секунд только когда вкладка видима. Активным считается дневной ID, от которого был heartbeat за последние 150 секунд. Это делает показатель устойчивым к кратким задержкам сети и закрытию вкладки без отдельного события logout.
