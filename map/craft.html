Актуализация каталога

Обновить данные крафта

Приложение загрузит данные из API Odium World, сравнит их с локальной базой и сохранит новую версию только при успешной загрузке и наличии изменений.

Сначала приложение попробует запрос без токена. Если API потребует авторизацию, вставьте Bearer-токен из DevTools → Network → Request Headers → Authorization. Токен не сохраняется в локальной базе или метаданных обновления.
